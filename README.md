# SciList

Flutter-приложение для проверки научных журналов по ISSN в «Белом списке» РЦНИ
(<https://journalrank.rcsi.science>).

## Возможности

- Поиск журнала по ISSN: маска ввода `XXXX-XXXX`, проверка формата и контрольного номера ISSN.
- Карточка журнала: названия (в т. ч. английское), ISSN, уровни 2023/2025/2026, тип отметки,
  примечание, даты включения/исключения, ссылки на журнал.
- Избранное и история поиска — хранятся локально в `SharedPreferences`.
- Проверка обновлений: последний релиз GitHub, сравнение версий по числам,
  проверка не чаще раза в 6 часов, ручная кнопка в настройках и «Пропустить версию».
- Светлая и тёмная темы, только портретная ориентация.

## Запуск

```bash
flutter pub get
flutter run          # запуск на подключённом устройстве/эмуляторе
flutter test         # тесты (маска ISSN, сравнение версий, разбор релиза, таймер проверки)
flutter analyze      # статический анализ
```

Приложение не требует ключей и авторизации: используется открытый API РЦНИ.
